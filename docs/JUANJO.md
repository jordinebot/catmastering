# Afegir un treball

**No cal editar fitxers, ni instal·lar cap programa.** Només cal iniciar sessió amb un compte GitHub autoritzat.

1. Obre el formulari [Afegir un treball](https://github.com/jordinebot/catmastering/issues/new?template=add-credit.yml).
2. Escriu l'artista i el títol tal com han d'aparèixer al web.
3. Escriu la data com `AAAA-MM-DD`. Si només saps l'any, posa `AAAA`.
4. Adjunta una portada JPG, PNG o WebP (fins a 10 MB) al camp Portada.
5. Prem **Submit new issue**.
6. Espera que el mantenidor revisi la proposta. L'estat «pendent de revisió» vol dir que encara no s'ha publicat.

Quan s'aprovi i es fusioni la proposta, el lloc es desplegarà automàticament. Si t'equivoques, afegeix una nota a l'issue perquè el mantenidor corregeixi la proposta. Si la portada no es pot llegir, torna a adjuntar-la a la issue o espera que el mantenidor et contacti. No enviïs una segona issue pel mateix treball.

El workflow automàtic està limitat als comptes indicats a la configuració privada del repositori. Si el sistema no et deixa enviar la proposta, demana al mantenidor que t'afegeixi com a usuari autoritzat.
